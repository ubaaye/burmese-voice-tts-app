❓ မေးခွန်းများ

Edge TTS အခမဲ့ က အကန့်အသတ် ရှိလား?
ရှိပါတယ် — ၁ နာရီလျှင် အကြိမ် ၁၂၀ အထိ သုံးနိုင်ပါတယ်။ စာရှည် ရေးရင် အပိုင်း ပိုင်းထုတ်ပြီး ထုတ်ပေးလို့ အကြိမ်ရေ ပို ကုန်နိုင်ပါတယ်။
Pro ဆိုတာ ဘာလဲ? Key / Code ဘယ်လို ရမလဲ?
ElevenLabs / Gemini / F5 Clone က Pro feature တွေပါ။ ကိုယ်ပိုင် API key ကို Login ဝင်ပြီး Menu → «My Keys & Pro Code» မှာ ထည့်ရင် code မလိုဘဲ သုံးနိုင်ပါတယ်။ ဒါမှမဟုတ် ပိုင်ရှင် ပေးတဲ့ Pro code ထည့်ရင် owner ရဲ့ key နဲ့ သုံးနိုင်ပါတယ်။
ကိုယ့် API key လုံခြုံရဲ့လား?
Key တွေကို သင့် အကောင့်ထဲမှာပဲ သိမ်းထားပြီး သင့် တောင်းဆိုမှုတွေ အတွက်ပဲ သုံးပါတယ် — သူများ မမြင်နိုင်ပါ။ စိတ်ချချင်ရင် ဒီ app အတွက် သီးသန့် ထုတ်ထားတဲ့ key ကိုပဲ ထည့်သုံးပါ၊ မသုံးတော့ရင် မူရင်း နေရာကနေ အချိန်မရွေး ပြန် ပိတ်လိုက်လို့ ရပါတယ်။
VoxCPM ကို ဘာလို့ အမြဲ သုံးလို့ မရတာလဲ?
VoxCPM က သီးသန့် GPU session ဖွင့်ထားတဲ့ အချိန်မှပဲ အလုပ် လုပ်ပါတယ်။ admin က switch ဖွင့်ပြီး session ရှိနေတဲ့ အချိန်မှသာ သုံးနိုင်ပါတယ် — ပိတ်ထားချိန်မှာ တခြား engine တွေ ဆက် သုံးနိုင်ပါတယ်။
အသံ မထွက်ရင် / ဆာဗာ နိုးချိန် ကြာရင် ဘာလုပ်ရမလဲ?
ဆာဗာက အခမဲ့ အဆင့် ဖြစ်လို့ အိပ်ပျော်နေရင် ပြန် နိုးဖို့ ~၁ မိနစ် လောက် ကြာနိုင်ပါတယ်။ ခဏ စောင့်ပြီး «ပြန် စမ်းမယ်» ခလုတ် နှိပ်ပါ — အင်တာနက် ချိတ်ဆက်မှုလည်း စစ်ကြည့်ပါ။
ဆက်သွယ်ရန်: TikTok @old.burma.com
